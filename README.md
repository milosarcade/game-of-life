# Conway's Game of Life

Draw cells on the grid, press play, and watch them live, die and multiply
by four simple rules. Includes step-by-step tutorials for building famous
patterns.

Try it: https://milosarcade.com/game-of-life/

## Controls

| Input | Action |
|---|---|
| Left-drag | Draw cells |
| Alt + drag, or E | Erase |
| Scroll | Zoom |
| Right-drag, or Space + drag | Pan |
| Space | Play or pause |
| . | Step one generation |
| F | Fit to screen |

## Patterns to stamp

Glider, Lightweight spaceship, Pulsar, Gosper glider gun, Lightweight
spaceship gun, Direction changer, Switch engine, R-pentomino, Acorn and
Diehard.

## Tutorials

Build a glider, a lightweight spaceship, a pulsar, a glider gun, an
endless nuke, a direction changer and a spaceship gun.
